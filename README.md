# AI Inference Labs

Practical writing and runnable experiments about AI inference infrastructure.

## Start here

The first article and Go streaming gateway are being prepared on a review branch. Tutorials use Go and the standard library where practical. Examples that simulate inference are explicitly labeled, and benchmarks are never presented as measurements unless run.

## Editorial principles

- Explain the engineering problem before introducing the solution.
- Prefer short, direct prose and useful diagrams.
- Link primary sources and distinguish research claims from independent measurements.
- Keep tutorials reproducible using pinned source revisions and documented commands.
- Never invent production incidents or performance results.
